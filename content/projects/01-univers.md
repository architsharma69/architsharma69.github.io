## What I Built
- Wrote a time series analysis service for fault detection in escalators. Integrated with an internal email API to automatically send alerts once fault is detected. Increased fault detection frequency from weekly to daily.
- Created an internal chatbot for company staff to easily access company documents. Used AI with a vector database to allow for semantic searching of whole documents or specific pages.
- Designed a team of AI agents to conduct data validation of large datasets containing HVAC sensor information. Streamlined data validation pipeline by automating data validation process. Reduced duration from one week to 10 minutes.
- Learned how to use CrewAI, a python module for AI agents.
- Leveraged Docker and Cron to deploy code to the corporate cloud, ensuring consistent and reliable execution. Deployed 3 separate services to company servers.
